# KalaSetu web assets

Place visual resources for the Next.js web experience in this directory.
Everything here is served directly from the site root, so a file such as
`public/assets/brand/logo.svg` is referenced as `/assets/brand/logo.svg`.

## Folders

- `brand/` — approved KalaSetu logos, wordmarks, and marks
- `heroes/` — landing-page and hero imagery
- `products/` — approved product/catalog imagery
- `icons/` — interface and craft icons
- `patterns/` — restrained decorative craft motifs and separators
- `fonts/` — licensed font files, when needed for multilingual support

Keep text out of images, preserve natural product colors, and label synthetic
demo imagery clearly in the UI. Do not add secrets, user uploads, or generated
build output here.
