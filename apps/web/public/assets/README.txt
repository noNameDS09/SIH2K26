KalaSetu frontend supporting assets
===================================

Product photos (pots, stoles, boxes, bags, diyas, etc.) were intentionally excluded.

These are recreated / isolated supporting decorations from the page designs:
leaves, logos, landscapes, artisan illustrations, basket sketch, and the diamond pattern.

JPG = original generated files on white or cream.
PNG = white background knocked out (best for leaves, logos, line illustrations).

Suggested use
-------------
- leaf-branch-tall / leaf-branch-simple / leaf-sprig-small
  Sidebar and corner decorations (catalog, insights, marketplace, sales)

- logo-kalasetu-english
  Primary wordmark

- logo-kalasetu-devanagari
  Alternate wordmark used on product-flow screens

- logo-mark-gateway
  Icon-only mark / favicon-style

- illustration-village-hills-footer
  Product detail page bottom landscape

- illustration-village-watercolor
  Softer landscape variant

- illustration-temple-hill-banner
  Small "bigger tomorrow" style header landscape

- illustration-hillside-panel
  Tall right-rail landscape (upload screen)

- illustration-artisan-painting
  Public catalog side illustration

- illustration-artisan-speaking
  Sales / trade-record helper illustration

- illustration-crafts-still-life
  Empty sales-state decorative illustration

- illustration-woven-basket
  Distribution page side sketch

- pattern-diamond-jaali
  Pricing page side pattern

Note
----
These are high-quality recreations matching the design style, not lossless crops
from the mockups (mockup crops stay compressed and look soft on a real site).
Logos are style-matched, not official vector brand files.
If you need a specific asset redrawn (different crop, transparent only, flipped
leaf, darker green, etc.), say which file and how to change it.
